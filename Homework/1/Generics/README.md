## 1. Реализовать обобщённый класс PriorityQueue<T>

### Описание
Очередь, из которой элементы извлекаются по убыванию приоритета (чем больше число, тем выше приоритет). Если у элементов одинаковый приоритет, они извлекаются в порядке их добавления (принцип FIFO)

### Поля класса

| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| `priorityExtractor` | `Function<T, Integer>` | Функция, которая считает приоритет для элемента |
| `heap` | `PriorityQueue<Element<T>>` | Встроенная очередь Java, которая хранит обернутые элементы |
| `idCounter` | `long` | Счетчик, который запоминает порядок добавления элементов |

### Внутренний класс Element<E>
Хранит три значения:
* `value` (тип `E`) — сам элемент
* `priority` (тип `int`) — его приоритет
* `id` (тип `long`) — порядковый номер добавления

### Методы
* `CustomPriorityQueue(Function<T, Integer> priorityExtractor)` — Конструктор, принимает функцию приоритета и настраивает логику сравнения элементов (сначала по приоритету, затем по id)
* `void add(T item)` — Добавляет элемент в очередь, считает его приоритет и выдает ему уникальный id.
* `T poll()` — Извлекает и возвращает элемент с самым высоким приоритетом. Если очередь пуста, возвращает null.
* `boolean isEmpty()` — Возвращает true, если в очереди нет элементов.

## 2. Иерархия животных (Animals)

### Описание
Показывает наследование в Java и используется для демонстрации работы генериков

### Класс Animal
Базовый класс для всех животных
* **Поля:** `String name` (имя животного)
* **Конструктор:** `Animal(String name)` — принимает и записывает имя

### Класс Dog (наследует Animal)
* **Конструктор:** `Dog(String name)` — передает имя в главный класс Animal
* **Методы:** `void bark()` — выводит в консоль, что собака лает

### Класс Cat (наследует Animal)
* **Конструктор:** `Cat(String name)` — передает имя в главный класс Animal
* **Методы:** `void meow()` — выводит в консоль, что кошка мяукает

## 3. Утилиты для работы со списками (AnimalUtils)

Методы используют специальные wildcard-символы (`? extends` и `? super`)

* `copyAnimals(List<? extends Dog> src, List<? super Animal> dst)` — Копирует всех собак из списка `src` в конец списка `dst`
* `fillWithCats(List<? super Cat> dst)` — Очищает список `dst` и добавляет туда трех новых кошек (`cat1`, `cat2`, `cat3`)
* `safeTransfer(List<? extends T> src, List<? super T> dst)` — Универсальный метод. Переносит все элементы из исходного списка в целевой, после чего полностью очищает источник
